## 🧩 功能特性

| 功能 | 说明 |
|------|------|
| ✅ **双击隐藏桌面图标** | 桌面**空白处**双击，平滑渐隐 / 渐显（约 0.5s）；双击图标本身仍正常打开应用，绝不误触发；每次物理双击 1:1 切换，动画期间请求排队 |
| ✅ **任务栏** | 透明任务栏（Win10 Accent API / Win11 内嵌 TranslucentTB 便携引擎，全屏自动恢复不透明）+ 自动隐藏（开启即隐藏，鼠标移到屏幕下边界弹出） |
| ✅ **主机性能监控** | CPU / GPU / 内存 / 网络实时曲线与关键明细，参照任务管理器性能页；本地采样，刷新间隔 200 / 500 / 1000ms 可选 |
| ✅ **隐私操作** | 空闲超时自动最小化所有窗口、隐藏图标与任务栏并静音，一操作鼠标键盘立即全部还原；支持**老板键**（默认 `Ctrl+``，按下立即触发、再按恢复，老板键触发后鼠标键盘不恢复） |
| ✅ **AI 助手** | 接入你自己的 OpenAI 兼容接口（支持 DeepSeek 等自定义 BaseURL）：流式回复、多轮上下文、可停止 / 清空；API Key 经 Windows DPAPI 加密落盘；另附 **AI 小窗**（默认 `Ctrl+Shift+Space` 随时呼出） |
| ✅ **音频识别** | 桌面右下角液态玻璃媒体面板：音源 / 封面 / 进度 / 波形，上一首 · 暂停播放 · 下一首控制（网页音频自动置灰切歌）；**面板内系统音量滑块 + 静音**；SMTC 本地读取 + WASAPI 波形，无播放自动隐藏；设置中可调**背景透明度**并开**鼠标穿透**（仅展示/可操作） |
| ✅ **鼠标选取翻译** | 任意应用**选中文字松手**即弹出「翻译」按钮，点击出翻译界面（点击其他位置 / Esc 关闭）；引擎可选你配置的 **AI 助理**（复用 Key / 模型）或 **微软翻译**（Azure Translator，Key 加密保存） |

**贯穿全局**：花笺纸感三主题（浅色 / 深色 / 跟随系统）· 无边框圆角窗口 · 关闭到托盘 · 开机自启动（启动文件夹快捷方式）· 开关状态记忆（重启自动恢复）· 纯本地、不联网、不写注册表、退出即还原。

## 快速开始

### 直接使用

从 [GitHub Releases](https://github.com/LiuBe-github/CloudSatchel/releases) 下载：

| 产物 | 说明 |
|------|------|
| `CloudSatchel_<版本>_x64-setup.exe` | NSIS 安装包（简体中文） |
| `CloudSatchel.exe` | 免安装便携版，单文件即跑 |

需要 **Windows 10 / 11**（依赖 WebView2 Runtime，系统通常已内置）。

### 从源码构建

需要 **Node.js 18+** 与 **Rust 工具链**（rustup stable + MSVC）。

```bash
# 1. 构建前端（React + TS + CSS）
npm --prefix ui install
npm --prefix ui run build

# 2. 编译桌面壳（首次较慢，需下载依赖）
cd src-tauri
cargo build --release
cd ..

# 3. 运行
start src-tauri\target\release\CloudSatchel.exe
```

Windows 下双击 `build.bat` 一键构建；双击 `launch.bat` 一键启动（开发模式）。

## ⚙ 技术架构

| 模块 | 实现 |
|------|------|
| 前端 | React 19 + TypeScript + Vite（`ui/`），CSS 变量三主题 |
| 桌面壳 | Tauri 2（Rust），无边框窗口 + WebView2 渲染，多窗口路由（主窗口 / AI 小窗 / 音频面板） |
| 图标隐藏 | 对 `SHELLDLL_DefView` 设 `WS_EX_LAYERED` + alpha 逐帧渐变 |
| 双击检测 | `WH_MOUSE_LL` 低层钩子，自检双击序列 + 基于桌面列表**选中状态**的无指针判定（不向 Explorer 发带指针消息，避免崩溃） |
| 任务栏透明 | Win10 Accent API / Win11 内嵌 TranslucentTB 便携引擎（引擎文件固定 2000-01-01 时间戳，杜绝误弹更新） |
| 空闲检测 | `GetLastInputInfo` 轮询，隐私操作 / 任务栏自动隐藏共用 |
| 全局热键 | `RegisterHotKey` 独立消息循环线程（老板键 / AI 小窗），防连发、注册失败降级提示 |
| AI 对话 | Rust `reqwest` 代理 OpenAI 兼容 Chat Completions（SSE 流式 → Tauri 事件逐字推送）；Key 用 Windows DPAPI 加密落盘 |
| 音频识别 | SMTC（`GlobalSystemMediaTransportControlsSessionManager`）读会话 + 控制；WASAPI loopback + 512 点 FFT → 16 档波形，静音自动停止采集；背景透明度走 CSS 变量、鼠标穿透走窗口 `WS_EX_TRANSPARENT`；音量滑块走 Core Audio `IAudioEndpointVolume` |
| 鼠标选取翻译 | `WH_MOUSE_LL` 钩子监听左键抬起 + UI Automation（TextPattern）读取选中文本与选区位置 → 小按钮窗 / 翻译弹窗（点击外部 / 失焦 / Esc 关闭）；翻译走 AI 兼容 Chat Completions 或 Azure Translator v3（Key DPAPI 加密） |
| 设置持久化 | `%LOCALAPPDATA%\CloudSatchel\settings.json`（`prefs` 模块，原子写入），启动自动恢复并应用效果 |
| 辅助窗口 | 无边框透明小窗完整配方：WS_POPUP + TOOLWINDOW（不进 Alt+Tab）+ DWM 圆角 + `focusable:false`（杜绝激活 caption）+ WM_NCCALCSIZE 全客户区 |

> 历史教训：跨进程向 Explorer 发送带指针的 ListView 消息会导致资源管理器崩溃（`comctl32.dll` 访问违例），全部判定已改为无指针方案；系统级 Acrylic 毛玻璃与 WebView2 透明背景不兼容（渲染成灰色），玻璃质感一律用 CSS 拟态实现。

## 🌿 纯净性说明

- 前端静态资源本地加载，**不联网**（唯一例外：AI 助手仅在用户主动发送消息时请求所配置的接口地址）
- **不写注册表**（主题跟随系统仅读取；自启动用启动文件夹快捷方式；任务栏隐藏不写注册表）
- 后台驻留由「关闭到托盘」开关控制（默认开启）
- 退出时自动恢复桌面图标与任务栏；异常退出后下次启动自动自修复
- AI 对话历史仅存内存、退出即清；API Key DPAPI 加密落盘，日志无明文

## 已知限制

- 仅支持 Windows 10 / 11（依赖 `SHELLDLL_DefView` 窗口类与 WebView2 Runtime）
- SMTC 媒体会话需要 Win10 1809+（更早版本音频面板自动隐藏）
- 从源码构建需要 Node.js 18+ 与 Rust stable（MSVC 工具链）
