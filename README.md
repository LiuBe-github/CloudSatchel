# 云笈 · Cloud Satchel

一个为 Windows 打造的**纯净本地桌面工具集**：界面参照「花笺 Floral Notepaper」的设计语言
（纸感配色 + 竹青绿强调色 + 噪声纹理 + 柔和动画），技术栈为
**React 19 + TypeScript + CSS 前端 · Tauri 2 (Rust) 桌面壳 · Win32 API 原生控制**。

当前包含两个工具：**双击隐藏桌面图标** 与 **透明任务栏**。

## 功能特性

- ✅ 花笺风格极简界面（纸感配色 + 竹青绿强调色），深色 / 浅色 / 跟随系统 三主题
- ✅ 双击隐藏桌面图标：桌面**空白处**双击，平滑渐隐 / 渐显（约 0.5s）
  - 精准判定：双击**图标本身**仍会正常打开应用，不会误触发隐藏
  - 每次物理双击 1:1 切换，动画期间到达的请求排队，绝不吞事件
- ✅ 透明任务栏：Win10 走 Accent API，Win11 内置 TranslucentTB 便携引擎
- ✅ 无边框圆角窗口，标题栏可拖动，Windows 风格窗口按钮（右上角）
- ✅ 关闭到托盘：设置开关可切换——开启后点击关闭最小化到托盘（后台继续运行，托盘图标随时恢复）；关闭后点击关闭直接退出
- ✅ 关于面板：标题栏 ⓘ 查看软件名称、版本、技术栈与仓库信息
- ✅ 开机自启动：设置面板一键开关（启动文件夹快捷方式，不写注册表、默认关闭）
- ✅ 纯净：本地运行、不联网、不写注册表、退出即恢复桌面图标与任务栏

## 快速开始

需要 **Node.js 18+** 与 **Rust 工具链**（rustup stable + MSVC）。

```bash
# 1. 构建前端（React + TS + CSS）
npm --prefix ui install
npm --prefix ui run build

# 2. 编译桌面壳（首次较慢，需下载依赖）
cd src-tauri
cargo build --release
cd ..

# 3. 运行
start src-tauri\target\release\CloudSatchel.exe
```

Windows 下直接双击 `build.bat` 可一键完成构建；双击 `launch.bat` 一键启动（开发模式）。

### 构建产物

| 产物 | 位置 |
| --- | --- |
| 免安装便携版 EXE | `src-tauri\target\release\CloudSatchel.exe` |
| NSIS 安装包 | `src-tauri\target\release\bundle\nsis\云笈_0.6.6_x64-setup.exe` |

生成安装包：在项目根目录执行 `npm run tauri build`（首次会下载 NSIS 工具链）。

> 前端产物嵌入在 EXE 内部（`ui/dist`），单文件即可运行，无需额外资源目录。

## 使用说明

| 操作 | 效果 |
| --- | --- |
| 点击主区域开关 | 激活 / 停用功能（ON=可双击隐藏，OFF=双击不生效） |
| 在**桌面空白处**双击 | 隐藏 / 显示桌面图标（仅当功能激活时生效） |
| 双击桌面**图标** | 正常打开应用，不会误触发隐藏 |
| 点击顶部 ⚙ | 打开 / 关闭设置面板（主题切换、开机自启动） |
| 点击顶部 ⓘ | 打开 / 关闭「关于」面板（软件基本信息） |
| 设置面板 → 外观主题 | 切换 浅色 / 跟随系统 / 深色 主题 |
| 设置面板 → 开机自启动 | 登录 Windows 后自动启动本应用（默认关闭） |
| 设置面板 → 关闭到托盘 | 开启：关闭窗口时最小化到托盘继续后台运行；关闭：点击关闭直接退出软件 |
| 点击关闭按钮（或 Alt+F4） | 按「关闭到托盘」设置执行：开启→最小化到托盘；关闭→直接退出（退出前自动恢复桌面与任务栏） |
| 托盘图标左键单击 | 恢复并聚焦主窗口 |
| 托盘图标右键菜单 | 显示主窗口 / 退出（退出前自动恢复桌面与任务栏） |

## 技术架构

| 模块 | 实现 |
| --- | --- |
| 前端 | React 19 + TypeScript + Vite（`ui/`），CSS 变量三主题 |
| 桌面壳 | Tauri 2（Rust），无边框窗口 + WebView2 渲染 |
| 图标隐藏 | 对 `SHELLDLL_DefView` 设 `WS_EX_LAYERED` + alpha 逐帧渐变（显示完保持 Layered，不做 clear） |
| 开关语义 | ON = 功能激活（桌面双击生效），OFF = 功能停用（双击不生效） |
| 双击检测 | `WH_MOUSE_LL` 低层钩子（Rust），自检双击序列（≤500ms 且位移 ≤8px）+ 250ms 防抖 |
| 图标/空白判定 | 基于桌面列表**选中状态**（无指针的 `LVM_GETNEXTITEM`）：点图标会选中该项、点空白会取消选中，仅“无选中项”触发；隐藏/动画中任意桌面双击都触发；读取不确定一律不触发 |
| 任务栏透明 | Win10：`SetWindowCompositionAttribute` Accent API；Win11：内嵌 TranslucentTB 便携引擎 |
| 后台驻留 | `tray-icon`（Tauri 2），托盘菜单 + 左键单击恢复窗口；关闭行为由「关闭到托盘」设置控制 |
| 开机自启动 | 启动文件夹 `.lnk` 快捷方式（`IShellLinkW` COM），不写注册表、无需管理员权限 |
| 防误触发 | 每次物理双击 1:1 切换，动画期间请求排队，绝不吞事件 |
| 前后端通信 | Tauri `invoke` command + `state-updated` 事件推送 |
| 前端嵌入 | 启用 `custom-protocol`，debug / release 均内置 `ui/dist`，无需开发服务器 |

> 历史教训：跨进程向 Explorer 发送带指针的 ListView 消息（如 `LVM_GETITEMAT`）
> 不可靠且会导致资源管理器崩溃，因此所有判定均已改为无指针方案。

## 纯净性说明

- 前端静态资源本地加载，不联网；Rust 后端仅调用 Win32 API 控制桌面图标窗口
- 不写注册表（主题跟随系统仅读取；自启动用启动文件夹快捷方式）
- 后台驻留由「关闭到托盘」开关控制（默认开启）；关闭该开关后点击关闭即完全退出
- 开机自启动为设置面板可选项（默认关闭），实现为启动文件夹快捷方式而非注册表项
- 退出时自动恢复桌面图标；异常退出后下次启动自动自修复
- 关闭窗口按「关闭到托盘」设置执行，不会弹出询问；默认最小化到托盘

## 已知限制

- 仅支持 Windows 10 / 11（依赖 `SHELLDLL_DefView` 窗口类与 WebView2 Runtime）
- 构建需要 Node.js 18+ 与 Rust stable（MSVC 工具链）
