## 云笈 v1.1.0 — 任务栏性能小组件

本次更新新增「任务栏性能小组件」：在主屏任务栏托盘区（输入法/时钟）左侧，以原生 Direct2D 渲染实时显示主机性能数值，类似 TrafficMonitor 的任务栏组件。

### 新功能

- **任务栏性能小组件**：显示 CPU 占用率、内存占用率、GPU 温度、网速（上行/下行），带标签的文字数值（如 `CPU 12% · 内存 45% · GPU 62°C · ↑1.2M ↓8.4M`）
- **原生渲染**：Direct2D + DirectWrite 直写任务栏，背景全透明只有文字，数值带重影描边，透明任务栏压在壁纸上也清晰可读；纯展示、鼠标穿透、不进 Alt+Tab、不抢焦点
- **可配置**：每个显示项可独立开关、上下移动排序、整体位置可左右微调（±150）
- **智能显隐**：任务栏不可见 / 自动隐藏滑出中 / 存在全屏窗口 / 隐私模式触发时自动隐藏，恢复后自动回到任务栏
- **自动换行**：内容过宽时按「项」自动分为上下两行，不会拆散任何一项
- 刷新频率跟随性能监控采样间隔（下限 500ms）；默认关闭，在「主机性能监控」详情页「任务栏显示」开启

### 说明

- 仅支持屏幕底部的任务栏（竖向任务栏不显示）
- CPU 温度因 Windows 无公开读取接口（需内核驱动/提权，违背纯净性约定）未纳入小组件；GPU 温度通过 NVML 读取，非 NVIDIA 显卡显示 `--`

### 安装

下载下方 `CloudSatchel_1.1.0_x64-setup.exe` 安装即可，装机即用，无需额外运行库。
